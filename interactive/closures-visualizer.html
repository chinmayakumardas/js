Closures Visualizer

See how the inner function keeps outer variables alive

function outer() {
  let count = 0;
  function inner() {
    count++;
    return count;
  }
  return inner;
}

const counter = outer();
console.log(counter()); // 1
console.log(counter()); // 2

Key insight: When outer() finishes, its Execution Context is removed from the Call Stack. But inner still holds a reference to count. That preserved reference is the closure.
