# Phase 6 — Modern & Practical JavaScript

**Short Definition:** Everything modern JavaScript offers for real-world development — cleaner syntax, modules, better error handling.

**Goal:** Round out your toolkit and prepare for professional codebases.

---

## Topics

### Modern ES6+ Features
- Advanced destructuring
- Spread & rest (advanced)
- Tagged template literals
- Optional chaining (`?.`)
- Nullish coalescing (`??`)
- Logical assignment (`??=`, `||=`, `&&=`)

### Modules
- ES Modules (`import` / `export`)
- Named vs default exports
- Dynamic imports
- CommonJS mention (Node)

### Error Handling
- `try / catch / finally`
- `throw`
- Built-in error types
- Custom error classes

### Useful Built-ins
- `Date` object
- Regular Expressions (basics)

### Best Practices & Debugging
- Clean code, naming
- DevTools (breakpoints, watch, call stack)
- Reading error messages

### Capstone Ideas
- Weather app (Fetch API)
- Expense tracker (localStorage)
- Quiz app
- Simple Kanban board
