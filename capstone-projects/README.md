# Capstone Projects

These projects combine multiple phases.

## Recommended Order
1. **Quiz App** — conditionals, arrays, objects, localStorage
2. **Expense Tracker** — objects, arrays, localStorage, DOM basics
3. **Weather App** — Fetch API, async/await, JSON
4. **Simple Kanban Board** — arrays of objects, localStorage, UI state

## Definition of Done
- Works after refresh (if using storage)
- No console errors in normal flow
- Clear naming
- You can explain every line
