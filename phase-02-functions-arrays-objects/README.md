# Phase 2 — Functions, Arrays & Objects

**Short Definition:** Learn how to organize logic (functions) and data (arrays & objects). This is where you start writing real programs.

**Goal:** Move from single statements to reusable, organized code.

## Why this phase matters
Almost every real application is just **functions transforming data** (arrays & objects). Master this and everything later becomes easier.
