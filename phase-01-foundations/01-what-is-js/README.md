# What is JavaScript?

**Short Definition:**  
JavaScript is a high-level, dynamically typed programming language that runs in browsers and on servers (Node.js). It makes web pages interactive.

---

## Why it matters
It is the only language that runs natively in browsers. Almost every modern web app uses it.

---

## Key Points
- Created in 1995 by Brendan Eich at Netscape
- Runs in browser (Chrome V8, Firefox SpiderMonkey, Safari JavaScriptCore)
- Also runs on server via Node.js (uses V8)
- Dynamically typed → variables don’t have fixed types
- Single-threaded + Event Loop for async

---

## Browser vs Node.js

| Feature | Browser | Node.js |
|---------|---------|---------|
| DOM / window | Yes | No |
| fs / process | No | Yes |
| console / setTimeout / fetch | Yes | Yes |
