# Setup & First Program

**Short Definition:**  
How to run JavaScript using browser DevTools, VS Code, and Node.js + writing your first program with console and comments.

---

## Tools Needed
1. Browser (Chrome/Firefox) → DevTools (F12)
2. VS Code
3. Node.js (LTS)

---

## Console Methods
```js
console.log("Hello");     // normal output
console.warn("Warning");  // yellow warning
console.error("Error");   // red error
console.table([{a:1},{a:2}]); // table view
```

---

## Comments
```js
// single line comment

/*
  multi
  line comment
*/
```

---

## First Program
```js
// hello.js
console.log("Hello, World!");
console.log("Sum:", 2 + 3);
```

Run with:
- Browser → DevTools Console
- Node → `node hello.js`
