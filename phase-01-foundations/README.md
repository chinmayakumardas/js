# Phase 1 — Foundations

**Goal:** Get comfortable writing JavaScript. Stop being scared of the syntax.

This phase builds the mental model. Everything later (closures, async, React) sits on top of these fundamentals.

## Study Order (Strict)

Do **not** skip ahead. Type every example. Predict output before running.

After finishing this phase you should be able to:
- Explain `typeof null === "object"`
- Predict the result of `"5" + 2` vs `"5" - 2`
- Write clean `if`/`else` and loops without looking anything up
- Use `let` and `const` correctly
