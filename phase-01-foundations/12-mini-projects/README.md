# Phase 1 Mini Projects

Build these using only Phase 1 knowledge.

## 1. Calculator
Ask two numbers and an operator (+ - * /) using `prompt`. Show result.

## 2. Temperature Converter
Celsius ↔ Fahrenheit.

## 3. FizzBuzz
Print 1 to 100:
- multiple of 3 → Fizz
- multiple of 5 → Buzz
- both → FizzBuzz

## 4. Simple Guessing Game
Generate random number 1–10. Let user guess until correct. Count attempts.
